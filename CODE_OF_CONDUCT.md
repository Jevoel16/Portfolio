# Code of conduct

Be respectful in issues, pull requests and discussions here.

- Assume good intent and keep feedback about the work, not the person.
- No harassment, insults, or sexual or discriminatory language or images.
- Don't publish anyone's private information.

I may edit or remove comments, close threads or block accounts that break these rules. Report a problem privately through [GitHub's private vulnerability reporting](https://github.com/Jevoel16/Portfolio/security/advisories/new) or by contacting [@Jevoel16](https://github.com/Jevoel16) on GitHub.
