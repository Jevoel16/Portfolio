# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/Jevoel16/Portfolio/security/advisories/new) with the page or file, what you found and how to reproduce it.

I'll reply within 7 days and credit you in the fix unless you'd rather not be named.

## Supported versions

Only the live site, built from the latest commit on `main`, gets fixes.
